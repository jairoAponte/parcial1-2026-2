# Parcial 1 - Programación II - 2026-2

Este repositorio contiene las soluciones de la **Parte 2 del primer parcial de Programación II**, correspondiente al semestre 2026-2.

El propósito del repositorio es permitir la revisión de las soluciones después de la realización del parcial y servir como material de estudio.

## Contenido

El repositorio contiene las soluciones de los tres temas del parcial:

- `tema-a/WeeklyMuseumLog.java`
- `tema-b/MonthlyMuseumLog.java`
- `tema-c/WeeklyStudyLog.java`

Cada archivo contiene la implementación completa de la clase utilizada en la Parte 2 del tema correspondiente.

Las soluciones no realizan tratamiento explícito de excepciones. Cuando un método requiere determinadas condiciones para su uso correcto, estas se documentan como **precondiciones**.
